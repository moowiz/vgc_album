# Video Game Club × Big Walk

A tiny thank-you site for House House. Solve the panel, see the album.

Plain HTML, CSS and JavaScript. No build step. Open `index.html` in a browser.

## Editing

- **The answer** is the `ANSWER` constant at the top of `script.js`. Five characters, case-insensitive.
- **Photos** live in `assets/photos/`. Replace the placeholder SVGs with real images and update the `src` attributes in `index.html`. One group photo for the hero, four to six screenshots for the gallery.
- **Captions, intro, and notes** are plain text in `index.html`, in clearly commented blocks.
- **Symbols** in `assets/tiles/` are the game's peg-tile glyphs, used for decoration.

Once you have solved the panel in a tab, a refresh keeps the album open (session storage). Open a new tab to see the panel again.

## Hosting

The repo is ready for GitHub Pages: in the repo settings, set Pages to deploy from the `main` branch, root folder.
